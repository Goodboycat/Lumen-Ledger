# Lumen Ledger — repository root

- `LUMEN/game/` — **the game** (serve statically: `cd LUMEN/game && python3 -m http.server 3000`). See `LUMEN/README.md` and `LUMEN/game/README.md`.
- `LUMEN_extras/` — dev material (demos, handoffs, plans, screenshots).
- Web build zip: `bash LUMEN/game/tools/itch_zip.sh` → `lumen-ledger-web.zip` (index.html at the zip root).
