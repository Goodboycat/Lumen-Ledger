# PLAY_BUGS — bugs found by playing (tools/play_record.mjs + the invisible recorder)

Each bug has an ID (`P##`). Status: OPEN / FIXED (commit msg contains the ID) / WONTFIX (reason).
Recordings: `LUMEN_extras/recordings/play_<stamp>.{webm,timeline.json,report.json}` (webm = canvas only, DOM HUD is not in it;
the timeline JSON has every bus event, key/pointer input and 1 Hz state samples with ms timestamps).
How to record: `cd LUMEN/game && python3 -m http.server 3000` (pm2) → `SEASON=20 NODE_PATH=tools/node_modules node tools/play_record.mjs 120`.
In a real browser: `?rec` autostarts, Ctrl+Shift+F9 toggles, `lumenRec.save()` downloads webm + json.

## Beta Playtest Report — Session 1 (2026-10-22)
- **Setup & Run Parameters**: `?notutorial&mute&nohistory&season=8&seed=1` (Story mode, 1280×720 desktop viewport, starting with `100 ✦` Spark, `260 ✦` Debt, `40%` Fog, and 3 starter stalls: `stall_fruit` at `(-6,-5)`, `stall_bread` at `(1,-5)`, `stall_tea` at `(-5,-8)`).
- **Gameplay & Economy Observations**:
  - Deployed an extra `stall_fruit` at `(2, 2)` for `60 ✦`, greeted Glimmers, collected tip coins, and allocated Spark using the `balanced` preset.
  - Completed Season 1 (`income: 41 ✦`, `expenses: 154 ✦`, `interestPaid: 52 ✦`, `upkeep: 42 ✦`, `debt: 260 → 312 ✦`, `fog: 45%`) and advanced into Season 2 via the Season Ledger modal.
- **Targeted Bug Reproductions in Session 1**:
  1. **Border Slash Out-of-Bounds Soft-Lock (`P11`)**: Walked Pip to the eastern island border `(11.35, 0)` facing `+X` (water) and triggered sword slash (`doAttack()`). The `strike` + `follow` lunge pushed Pip to `(11.75, 0)` (`Math.round(x) = 12`, water). Subsequent `KeyA` (`-X`), `KeyW` (`-Z`), `KeyS` (`+Z`), and `KeyD` (`+X`) inputs produced `0` movement (`vel = 0, 0`) because `isLand(nx, nz)` is `false` for every single-frame step from `11.75`, leaving Pip permanently stuck outside the island able only to repeat attack animations. Reproduced identically at the northern border `(0, -10.35) → (0, -10.75)`.
  2. **Cannot Sell Already-Spawned Stalls and Props (`P12`, `P13`, `P14`, `P16`)**:
     - Attempted to sell pre-spawned world props (`crate` at `(6,-5)`, `barrel` at `(7,-5)`, `jar_spend` at `(-8,3)`, `cottage` at `(-6,6)`): all are registered as `SCENERY` in `sb.build.cells` and ignored by demolish mode (`0 ✦` refund, never removed).
     - Attempted to sell starter stalls (`stall_fruit`, `stall_bread`, `stall_tea`): selecting their card in the Build Tray shows `1 placed` but offers no Sell/Demolish button in the detail bar (`P12`). Clicking `💥 demolish` in the footer and closing the Build Tray to click the stall on the map silently cancels `lg.demolishMode` while leaving the `💥 demolish` button visually active (`P13`).

## Beta Playtest Report — Session 2 (2026-10-22)
- **Setup & Run Parameters**: `?notutorial&mute&nohistory&season=8&seed=2026&touch=1` (Story mode with Touch UI enabled, seed `2026`, testing mobile/touch controls, isometric raycast accuracy, western/southern borders, and save snapshots).
- **Targeted Bug Reproductions & New Findings in Session 2**:
  1. **Isometric Parallax When Tapping Stall Roofs/Signs in Demolish Mode (`P17`)**: Even when keeping the Build Tray open with `lg.demolishMode = true`, clicking the visual body/roof/sign of a spawned stall (`y = 1.8 u` on `stall_fruit` at `(-5.5, -0.5)`) projects via `Input._project()` onto the `y = 0` plane at `(-6.19, -2.24)`—a **`1.87 u` ground offset** behind the stall. Because `lg.demolishMode` only searches `build.nearest(world.x, world.z, 1.2)` (`1.2 u` radius) and `occupied()` hits `SCENERY` first (`P14`), clicking the stall's awning/sign resolves to `{ id: 'scenery', scenery: true }` and fails to sell/demolish the stall.
  2. **Western & Southern Border Lunge + Save Slot Soft-LockPersistence (`P11`, `P18`)**:
     - Walked Pip to the western border `(-6.35, 0)` facing `-X` and used slash (`doAttack`), lunging out of bounds; also tested `playMove('hammer')` (`+0.15 u` lunge in `src/anim/heroAnims.js:126`) and `build` (`-0.2 u` backward hop in `src/anim/heroAnims.js:218`) near the southern border `(0, 12.42)`.
     - Confirmed that taking a save snapshot (`lg.save.snapshot()`) while Pip is out of bounds records the water coordinates verbatim (`P18`), which persists the movement soft-lock on `CONTINUE`.
  3. **Direct `BuildSystem.demolish()` Scenery Vulnerability (`P19`)**: Verified that `BuildSystem.demolish()` lacks an internal `if (entry.scenery) return false;` check, so any caller that does not pre-filter `!e.scenery` corrupts the `SCENERY` cell map.
